# iPhone Chrome／Safari確認手順

## 準備

1. iPhoneのChromeで https://ebiko5555.github.io/nail-tracking-lab/ を開く。Safariでも同じURLを使える。
2. 「カメラ開始」を押してカメラを許可する。モデル取得にネット接続が必要。画像はアプリから外部へ送らない。
3. 明るい場所で手の甲側をカメラに向け、指先まで画面に入れる。片手のみを対象にする。

## 8条件

各条件で10秒程度、`DEBUG` と `NAIL OVERLAY` を切り替えて観察する。できれば画面収録して、録画は本人の管理下に置く。

| 条件 | 操作 | 見る点 |
|---|---|---|
| 左右移動 | 手を画面の左右へ往復 | 爪の中心が指先から外れないか |
| 上下移動 | 手を上下へ往復 | 同上 |
| 接近 | 手をカメラに近づける | 幅と長さの追従、画面端の不明扱い |
| 離反 | 手を遠ざける | 小さくなった時の認識喪失 |
| 傾き | 手首を左右に傾ける | 回転角と鏡映の一致 |
| 曲げ | 1本ずつ指を曲げる | 位置・角度の追従 |
| 近接 | 指同士を寄せる | 品質が不明に変わるか |
| 重なり | 指先を一時的に重ねる | 飛び移りを避け、保持後に消えるか |

## 記録

- `DEBUG` の描画FPS、推論ms、描画msを各条件で記録する。
- 静止した手で30秒観察し、色付き輪郭の揺れと白破線との差を記録する。
- 「1フレーム固定」で5本の輪郭を手動指定し、中心差と面積比を記録する。
- 手が消えてから薄い保持が消えるまで、再登場して認識が戻るまでを画面収録から確認する。
- 左右反転をオフ／オンにし、動画と輪郭が同じ側へ動くことを確認する。
- iPhone機種、iOS、Safari、照明、手とカメラの距離、モデル初回読込時間、発熱の有無を記録する。

基準未達の場合は条件ごとに実測値を記録し、原因を「推論時間」「描画時間」「追跡喪失」「輪郭推定誤差」に分ける。この環境ではiPhone実機での測定値はまだない。
