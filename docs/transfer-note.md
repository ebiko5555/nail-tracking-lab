# 将来の移植メモ

このプロジェクトはTSUYAから独立している。移植するなら、まず `src/tracking/types.ts`、`estimate.ts`、`stabilize.ts`、`contour.ts` を対象にする。`main.ts` はカメラ取得と実験UIのため、そのまま持ち込まない。

入力はMediaPipeの21点（正規化x/yと相対z）、出力は5指別の中心・幅・長さ・角度・向き・幾何品質・状態。`estimateNails` は純粋関数、`NailStabilizer` は時系列状態を持つ。`tracked` 以外は現在の検出として扱わない。`held` は最大350 msの過去位置で、フェード用だけに使う。

移植前に必要なこと：iPhone実機で8条件の計測、手動輪郭を正解データとして多数収集、爪専用モデルの精度・速度・権利の確認、MediaPipeモデルの商用条件確認、カメラと描画の座標変換の再検証。複数手、極端な横向き、爪の3D曲面には現方式だけでは対応しない。
