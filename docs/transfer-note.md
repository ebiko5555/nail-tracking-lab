# 将来の移植メモ

このプロジェクトはTSUYAから独立している。移植するなら、まず `src/tracking/types.ts`、`estimate.ts`、`stabilize.ts`、`contour.ts`、`contourCalibration.ts`、`geometry.ts` を対象にする。`main.ts` はカメラ取得と実験UIのため、そのまま持ち込まない。

カラー描画は `src/tryon/polish.ts` に分離した。これは爪の推定形状に色を塗る試作用表示で、追跡の出力とは独立している。移植する場合は追跡の評価を先に行い、描画の採用は別に判断する。

入力はMediaPipeの21点（正規化x/yと相対z）、出力は5指別の中心・幅・長さ・角度・向き・幾何品質・状態。`estimateNails` は純粋関数、`NailStabilizer` は時系列状態を持つ。`tracked` 以外は現在の検出として扱わない。`held` は最大350 msの過去位置で、フェード用だけに使う。

`contourCalibration.ts` は固定フレームで人が指定した爪輪郭を、中心・幅・長さ・角度に対する局所座標へ変換する。ライブではその局所座標を戻して描く。これは個人差の手動補正であり、遮蔽や3D回転に合わせて見える爪の境界を再認識する処理ではない。保存するのは局所座標だけで、固定画像は保存しない。将来専用モデルを導入するときは、この補正値とモデル出力を混同せずに別の情報源として扱う。

移植前に必要なこと：iPhone実機で8条件の計測、手動輪郭を正解データとして多数収集、爪専用モデルの精度・速度・権利の確認、MediaPipeモデルの商用条件確認、カメラと描画の座標変換の再検証。複数手、極端な横向き、爪の3D曲面には現方式だけでは対応しない。
