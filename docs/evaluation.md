# 追跡精度の評価方法

## 指標

- 描画FPS：Canvasへ描いたフレーム数/秒。`DEBUG`に表示。
- 推論時間：`detectForVideo` 呼出し1回の時間。`DEBUG`に表示。呼出し間隔は処理時間に応じて約65〜180 ms。爪専用モデルは未導入なので、その推論時間の計測値はまだない。
- 描画時間：Canvasへの1回の描画時間。`DEBUG`に表示。
- フレーム間変動：同じ指の補正後中心の前回との差。画面幅・高さで正規化した距離。
- 補正差：同時刻のフィルタ前後の中心差。遅れの代理指標だが、真の遅延そのものではない。
- 静止時の揺れ：手を固定した30秒の中心座標の標準偏差を、動画または保存した記録から集計する。現UIは直近値のみを表示する。
- 動作中の遅れ：画面収録をフレーム単位で見て、実際の爪と仮想爪の中心を別々に注釈し、距離と時間差を測る。
- 喪失・復帰：遮蔽開始から `held`、`lost`、再び `tracked` になる時刻を記録する。
- 輪郭の正確さ：固定フレームで手動多角形と仮想ネイルの推定輪郭の重なり率（IoU）、中心差、面積比を見る。IoU＝共通面積÷両者を合わせた面積。1に近いほど重なりが大きい。手動輪郭にも人手の誤差がある。1画像のIoUをリアルタイム追跡性能と取り違えない。

## 判定の注意

推定輪郭は指先の骨格点から算出したもので、爪境界を認識していない。幾何品質は内部の姿勢整合性の目安であり、認識精度の統計的な信頼度ではない。指が重なる、画面端へ出る、関節距離が小さすぎる場合は不明にする。追跡が切れた状態の淡い輪郭は `held` で、検出結果に数えない。30 FPSは目標値であって実測達成値ではない。

## 自動確認済みの範囲

`npm test` は5指の区別、指ごとの補正の独立性、指先近接時の不明扱い、追跡喪失後の保持・消去・復帰、異常なジャンプの拒否、平滑化した角度と描画方向の整合、輪郭IoUを合成座標で確認する。実映像の精度とiPhoneの速度はこのテストでは分からない。
