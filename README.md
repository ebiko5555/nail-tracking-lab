# NAIL TRACKING LAB

スマートフォンのカメラで片手の5指を追跡し、選んだネイルカラーを重ねながら爪位置の推定精度を調べる独立した技術検証アプリ。TSUYAのファイル・コードは使用も変更もしない。正本はこのディレクトリの `src/`、ビルド済みの静的サイトは `deliverables/web/`。

**iPhone Chromeで試すURL：** https://ebiko5555.github.io/nail-tracking-lab/  
Chromeで開き、トップ画面の「ネイルカラーを試す」→背面カメラを許可する。初回は手の認識モデルを約7.8 MB読み込むため、少し待つ。読み込み中もカメラ映像が表示され、停止してやり直せる。撮影画面上部の「← トップに戻る」でカメラを終了してトップへ戻る。背面カメラを利用できない場合はエラーを表示する。

## 何を調べるアプリか

カメラ映像の手に単色または5本別々の色を重ねて試せる。クリーム、ジェル風、シアー、マットの描き分けは簡易的な画面表現であり、実物の質感や物理的な反射を再現するものではない。MediaPipeが見つける関節点から爪位置を**推定**するため、実際の爪の輪郭をAIが認識した結果ではない。手の動きへの追従、位置の揺れ、認識喪失、個人差によるずれを別々に検証する。

## 起動

Node.js 20.19以上を用意し、このディレクトリで次を実行する。アカウントや有料APIは不要。

```sh
npm install
npm run dev
```

PCでは表示された `http://localhost:5173/` を開く。初回はGoogleの公開Hand Landmarkerモデルをダウンロードするためインターネット接続が要る。処理するカメラ映像を送るAPIは実装していない。MediaPipeのWASMはアプリと同じ場所から読み込む。補正値だけが「保存」ボタンを押した時に `localStorage` に残る。固定フレーム画像と手動輪郭は一時メモリ上に置き、比較結果のJSONは「比較結果を保存」を押した時だけダウンロードする。JSONには画像を含めない。

本番用ファイルは `npm run build` で `deliverables/web/` に出力する。`npm run preview` でPC上の確認ができる。静的ファイルだけで動くためGitHub Pagesなどに配置できる。公開手順は [docs/publish.md](docs/publish.md) を参照。iPhoneのカメラ利用にはHTTPSが必要なので、PCの開発サーバーを同じWi-Fi上でHTTP接続する方法では動かない。無料の静的ホスティングへ配置するか、信頼済み証明書を用いたローカルHTTPS環境で確認する。

合成座標テストの `npm test` は、TypeScriptを直接読み込めるNode.js 24以上で実行する。ビルドとアプリ起動はNode.js 20.19以上でよい。

## 実験方法

1. トップの「ネイルカラーを試す」を押し、背面カメラの許可を与える。左右反転の初期値はオフ。
2. 手の甲を映し、色見本またはカラーピッカーから単色を選ぶ。「5本別々の色」をオンにすると指ごとに選べる。仕上がりを切り替え、「色を外して比較」で元の手を確認する。
3. 色が出ないときは画面内に手の甲と指先を入れ、明るさを確保する。「追跡の表示・設定（研究用）」では `LANDMARK` の21点、`NAIL POSITION` の推定輪郭、`DEBUG` の補正前後を確認できる。「計測値を見る（研究用）」を開くと、描画FPS、推論時間、描画時間、各指の状態・変動を読める。
4. 「指ごとの位置・大きさを補正」を開き、指ごとに位置・幅・長さを調整する。保存操作をしない限り再起動後には残らない。
5. 「1フレーム固定」を押す。指を選び、爪の外周を順に3〜12点タップする。中心差と面積比で推定と手動輪郭を比較し、「再開」でライブ映像に戻る。

撮影画面から戻るには、上部の「← トップに戻る」を押す。ブラウザの戻る操作でもトップに戻り、カメラを停止する。映像が止まったように見えるときは、画面内の状態表示を確認する。「モデルを準備中」なら読み込み待ち、「手を見つけられません」なら照明・画角を確認する。「1フレーム固定中」なら「再開」を押す。エラーやカメラ切断では「カメラ開始」からやり直せる。ブラウザのタブを閉じてもカメラは停止する。

「幾何品質」は関節点の配置に関する独自の目安であり、実際の爪検出確率ではない。近接や画面端では不明にする。追跡が切れると最大350 msだけ薄く保持し、その後消す。`held` は現在検出中という意味ではない。

## 現状

- 実装済み：単色・5本別色のカラー選択と簡易的な仕上がり表示、PHASE 1の5指推定描画、PHASE 2の個別補正・One Euro Filter・補正前後比較・短時間保持、PHASE 3のモデル調査、PHASE 4の自動幾何テストと実機手順。
- 未実装：実際の爪輪郭を見つける専用AI、ネイルアートやプレスオンネイル、爪の3D面推定、物理ベースの質感表現、WebGL描画、iPhone実機での性能実測。輪郭は形状近似と手動指定のみ。
- 目標：描画30 FPS。実機での到達状況は未測定。推論は映像の縮小コピー（最大幅640 px）に対し、処理時間に応じて65〜180 ms程度の間隔で実行する。映像自体は認識・描画処理から独立して表示する。端末が熱くなる場合はカメラを停止する。

今後はiPhone実機で移動・傾き・指の重なりを測り、誤差と処理時間に基づいて推定とフィルタを調整する。爪の輪郭を検出する専用モデルは、ライセンスと端末内での精度・速度を確認できた場合にのみ独立モジュールとして追加する。TSUYAへの移植はこの検証後に判断する。

詳しくは [iPhone確認手順](docs/iphone-test.md)、[評価方法](docs/evaluation.md)、[ライセンスとモデル調査](docs/licenses-and-models.md)、[移植メモ](docs/transfer-note.md) を参照。

## 変更してはいけないもの

TSUYAと `00_Core/`、旧Vault、エクスポート元データ。このアプリ内でも撮影画像を自動保存しない。
